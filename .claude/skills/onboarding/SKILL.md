# 带新用户上手

## 原则

- **每次只问一件事**，等用户回答再往下走；不要一次列一大堆步骤。
- 基本信息只写用户亲口说的内容；证件号、手机号等个人信息**不要在回复里复述原文**。
- 用 personal-assistant 的 MCP 工具查真实数据，不凭猜测。
- 用户随时说"先到这"就停下，告诉他下次说"带我上手"会接着来。

## 你在哪里运行，决定能做什么

| | 终端里的 Claude Code | 页面右下角「问 Agent」 |
|---|---|---|
| 写基本信息 | 逐条复述、用户同意后用 `update_personal_profile` | 只能 `propose_profile_update`，告诉用户"请在下面的卡片里确认" |
| 开始办一件事 | 告诉用户在攻略库点那份攻略的「开始办」 | 同左 |
| 改材料放在哪（`config.yaml`） | 用户同意后可以写 | 不能写，只说明怎么改 |

## 步骤

### 1. 看现状（不用问）

调 `list_tracks` 和 `get_profile_gaps`（只看 `summary` 的数字），用一两句话告诉用户：
正在办几件事、基本信息填了多少。已经有进度的，问他是要接着办，还是从头走一遍上手流程。

### 2. 最近要办什么

问："最近有什么要办的事吗？比如哪国签证、哪个城市的补贴。"

- 调 `list_guides` 找对应的攻略。找到了 → 告诉他攻略名，请他到「攻略与办事」的攻略库点进去「开始办」，开好后说一声。
- 没找到 → 告诉他可以在攻略库点「+ 新建攻略」，把几篇小红书帖子的分享链接贴进去，Agent 会整理成攻略。
- 只是想先看看 → 首页「办理中」为空时有「先看一个示例」按钮。

### 3. 补常用的基本信息

用 `get_profile_gaps` 里 `missing` 的字段，按这个顺序**每次问 3–5 项**：

1. 姓名拼音（姓 / 名）、中文姓名、性别、出生日期、出生地
2. 护照号、签发日期、有效期
3. 手机、邮箱、家庭住址
4. 婚姻状况、工作或学校

用户说"没有"的（例如没有曾用名），终端里用 `confirm_personal_profile_none` 记下；页面里告诉他可以在「我的资料 › 基本信息」里标"我没有这项"。

### 4. 登记材料

告诉用户到「我的资料 › 材料库」点「新增材料」，先登记办这件事最常用的几份（护照、身份证、银行流水、在职或在读证明），写上取得日期；文件可以一起上传，也可以以后再传。材料快过期时首页会提醒。

登记好后，调 `get_track`（如果已经开始办了）看看"还缺什么"，告诉他缺的前三项。

### 5. 要网申的话：填表插件

问："这件事要在官网上填表吗？"要的话，告诉他装 Chrome 插件（仓库 README「可选：填表插件」三步）：
装好后在官网上点「填本页」，常见格子一次填完，填不了的标红，侧边栏点一下复制。
条款禁止自动化的网站（例如澳洲 ImmiAccount），插件会先显示条款，要他自己决定。

### 6. 收尾

用 1–3 条告诉他接下来做什么（例如"去开始办 XX""把护照信息补上""登记银行流水"），不重复前面说过的话。
