# 会成长的个人助手（材料与表单管理）

## 这是什么


## Intent（我们真正想解决的问题）

起点是一次真实经历：办理澳大利亚签证时，材料分散在各处，其中银行流水、工作证明等有时效性，容易搞不清哪些已备齐、哪些要更新；网站表单填写这一步用 Agent 做过一次，可行但慢——因为每次都在从零探索网页结构。

值得解决的核心问题：
1. 材料状态（有没有、是否过期）应该能随时查到，而不是每次要用的时候现翻。
2. 网站表单填写的"探索"只应该发生一次；探索结果应变成之后能反复使用的资产。
