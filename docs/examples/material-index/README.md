# 材料索引格式示例（虚构数据）

材料索引存的是每份材料的**结构化元数据**（YAML）：类型、日期、状态、文件路径，不是真实材料文件本身。

**真实的索引不在仓库里。** 从 2026-09-24 起，它放在材料根目录下的 `index/`（材料根目录由
`config.yaml` 的 `materials_root` 决定，默认是仓库里被 git 忽略的 `materials/`）：

```
<材料根目录>/
  index/
    applications/<id>.yaml   # 一次签证申请（VisaApplication）
    records/<id>.yaml        # 一条材料记录（MaterialRecord）
  passport_scan/ ...         # 真实文件本身，记录里的 file_ref 是相对材料根目录的路径
```

这个文件夹里 `example-` 开头的文件全是**虚构数据**，只用来演示格式，程序不会读取它们。
字段说明见 `src/core/models.py` 里的注释。平时新增材料请直接在界面「我的资料」里上传，不需要手写 YAML。

## 为什么搬出仓库

索引里有材料类型、办理日期、文件名，这些也是个人信息。之前它放在仓库里的 `materials_index/`，
后来虽然改成被 git 忽略，但旧的提交里还有这些文件——在新旧版本之间合并或切换时，git 会把它们当成
"该删的文件"删掉（2026-09-24 真的发生过一次，从旧提交里恢复回来的）。放进材料根目录后，
git 从来没有追踪过这个目录，就不会再发生。
