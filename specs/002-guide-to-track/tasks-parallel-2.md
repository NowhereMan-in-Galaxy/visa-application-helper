## 任务 E：「02 我的资料」重新排版

**项目主反馈**：现在每条材料是一张大卡片、按钮竖排，新增表单常驻在页面上，整页"又臭又长，不够清晰明了"。

**可以改的文件**：`web/assets/my.js`、`web/assets/my.css`、`web/my.html`（只改 `<main>` 内部结构，侧边栏不动）。**不改** API、`guides.*`、测试以外的任何文件；不新增接口（现有接口足够）。

**目标版式**（从上到下）：

1. **标题区**：`我的资料` + 一句说明；右侧一个主按钮 `＋ 新增材料`。
2. **概览数字**（一行 4 个小格，用 guides.css 的 `.stats`/`.stat` 风格）：`材料总数`、`已过期`、`即将过期`、`待补`。数字为 0 的格子文字变灰；非 0 的"已过期"用 `--danger` 颜色。点击某个格子 = 在下方列表里只看这一状态（再点一次取消）。
3. **需要处理**（仅当有 已过期 / 即将过期 / 待补 的记录时显示）：一个醒目但紧凑的面板，每条一行：状态徽章 + 名称 + 一句原因（"已过期 N 天" / "N 天后过期" / "还没填取得日期"）+ 一个"更新"按钮（打开该记录的编辑）。
4. **两个标签页**：`材料库（N）` | `出行记录（N）`，同一时间只显示一个；当前标签记在 URL `#materials` / `#travel`，刷新后保持。
5. **材料库标签页**：
   - 工具栏：分类筛选（`全部 / 证件 / 财务 / 工作 / 证件照 / 其他`，带数量，样式同 guides.css 的 `.chips`/`.chip`）+ 搜索框（按 `type`、`sublabel` 过滤，输入即过滤）。
   - 列表用**紧凑的表格行**，每条一行，列：`状态`（徽章）、`材料`（type，下方小字 sublabel；示例记录加"示例"标签）、`取得日期`、`文件`（✓ / —）、`用在`（办事标题，多个用"、"连接；没有显示 —）、操作（`编辑` 链接按钮；PDF 记录多一个 `追加新页`）。
   - 点"编辑"：在该行**正下方展开**一行内联编辑区（字段同现在：type、sublabel、obtained_date、validity_days），`保存` / `取消`；同一时间只展开一行。
   - 不再按分类分成多个大面板；分类通过筛选 chip 完成。列表按 状态（已过期 → 即将过期 → 待补 → 已备齐）再按取得日期倒序排序。
   - 筛选后为空时显示一行"没有符合条件的材料"。
6. **出行记录标签页**：紧凑表格（国家、入境、离境、目的、操作），按入境日期倒序；`＋ 新增出行记录` 按钮展开一行内联表单；编辑同样行内展开。国家为空的行高亮提示"国家待补"。仍然**只读写 `travel_history`**，不展示姓名、证件号等字段。
7. **新增材料**：点标题区的 `＋ 新增材料` 才出现（面板或行内展开均可，默认收起），提交成功后收起并刷新；字段同现在。
8. **窄屏（≤ 650px）**：表格每行改为两行堆叠（第一行：状态 + 名称；第二行：日期 · 文件 · 用在 · 操作），不出现横向滚动。

**验收**（机械可查）：
- 页面加载后默认只显示"材料库"标签的内容，出行记录表格不在可见区域（`hidden`）；访问 `/my.html#travel` 默认显示出行记录。
- 新增材料表单默认 `hidden`，点 `＋ 新增材料` 后可见。
- 材料列表中每条记录只占表格的一行（`<tr>` 或等价的一行元素），编辑区展开时额外多一行，且同时最多一个编辑区。
- 点概览里"已过期"格子后，列表只剩状态为"已过期"的记录。
- `node --check web/assets/my.js` 通过；`uv run pytest tests -q` 仍全部通过；页面上不出现 "null"、"undefined"、"[object"（渲染时对数组和空值做过滤，参考 guides.js 的 `setView`/`el()`）。
- 用 curl 确认 `/my.html`、`/assets/my.js`、`/assets/my.css` 返回 200（服务端口用 8015，测完关掉）。
